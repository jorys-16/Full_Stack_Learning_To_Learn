# 🚀 Elite Full-Stack Web & AI Engineering Curriculum

Welcome to the single source of truth for my web engineering curriculum. This repository uses a **"Layered Learning" (200% Mastery)** approach: pairing hands-on project building (TTP, The Odin Project, JS Mastery) with rigorous algorithmic deep-dives, testing, and security training (CodeSignal / RippleMatch, Full Stack Open, & Frontend Masters).

### 🧠 Guiding Principles
1. **The 200% Rule:** Never learn a concept from just one source. Pair practical building with theoretical deep dives and technical interview assessments.
2. **Hands-On Over Passive Reading:** Watching tutorials without typing isn't learning. Write the code, break it, and debug it.
3. **Understand the Plumbing:** The front-end is just an interface. Real web engineering happens in secure API routes, database schemas, and state management.
4. **Security & Testing First:** Modern web dev isn't just about making things work; it's about making them secure and testable. CodeSignal's TDD and OWASP training runs parallel to every build.
5. **Pass the Interview, Build the Product:** Use RippleMatch/CodeSignal to pass the algorithmic filters, and use JS Mastery/TTP to build production applications.
